# Student Dropout Risk — 2026 Project

## Notebook

The project solutions and saved outputs are in `student_dropout.ipynb`.

The notebook uses Python and pandas to analyse student dropout risk
and combine student information with GDP data from Our World in Data.

## Running the notebook

Open `student_dropout.ipynb` in Jupyter and run the cells from top to bottom.
An internet connection is needed because both datasets are read from URLs.
